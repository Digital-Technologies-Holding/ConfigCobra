# Contributing to ConfigCobra

Thank you for your interest in contributing to ConfigCobra! 🎉 This document provides guidelines and instructions for contributing to the project.

## 🐛 Reporting Bugs

Found a bug? We'd love to hear about it! Use our **Bug Report** template to submit an issue.

### Before Submitting a Bug Report

- ✅ Check if the bug has already been reported on our [support page](https://configcobra.com/#contact)
- ✅ Make sure you're using the latest version of ConfigCobra
- ✅ Gather relevant information (browser, screenshots, error messages, steps to reproduce)

### How to Report a Bug

1. Go to the [ConfigCobra Support page](https://configcobra.com/#contact)
2. Fill out the bug report form with all relevant information
3. Submit your report

You can also use the bug report form on the support page, which will help us track and address your issue.

A good bug report should include:
- 📝 Clear description of the bug
- 🔄 Steps to reproduce the issue
- 💻 Environment details (browser, OS, etc.)
- 📸 Screenshots or error messages (if applicable)
- 🎯 Expected vs. actual behavior

## 💡 Feature Requests

Have an idea for a new feature or improvement? We welcome your suggestions!

### How to Request a Feature

1. Go to the [ConfigCobra Support page](https://configcobra.com/#contact)
2. Fill out the feature request form
3. Describe your idea in detail
4. Explain the use case and benefits
5. Submit your request

A good feature request should include:
- 📝 Clear description of the feature
- 🎯 Problem it solves or benefit it provides
- 💡 Potential implementation ideas (optional)
- 📊 Use cases or examples

## 📧 Alternative: Contact Form

You can submit bug reports and feature requests through our [support page](https://configcobra.com/#contact).

## 📋 Issue Guidelines

### Do's ✅

- ✅ Use clear, descriptive titles
- ✅ Provide detailed information
- ✅ Be respectful and constructive
- ✅ Follow the issue templates
- ✅ Check for duplicates before submitting

### Don'ts ❌

- ❌ Don't submit duplicate issues
- ❌ Don't use issues for general support questions (use email instead)
- ❌ Don't include sensitive information (credentials, API keys, etc.)
- ❌ Don't be rude or disrespectful

## 📚 Documentation Contributions

We welcome improvements to our documentation! Found a typo, unclear section, or want to add examples?

- 📝 Open an issue describing the documentation improvement
- 📧 Contact us at **info@digitechold.com** with your suggestions

## 🤝 Code of Conduct

Please be respectful and constructive in all interactions. We're all here to make ConfigCobra better!

## 🙏 Thank You!

Your contributions help make ConfigCobra better for everyone. We appreciate your time and effort! 💙
