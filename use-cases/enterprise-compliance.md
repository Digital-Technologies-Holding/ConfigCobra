# Enterprise Multi-Standard Compliance Use Case

## 🏢 Overview

Large enterprises often need to comply with multiple security and compliance frameworks simultaneously. ConfigCobra's comprehensive compliance mapping helps organizations manage multiple standards efficiently through a single assessment platform.

## 🎯 Key Compliance Requirements

Large enterprises typically need to meet:

- **SOC 2** - Customer trust and vendor management
- **ISO 27001** - International information security standard
- **ISO/IEC 27002:2022** - Information security controls
- **NIST CSF** - Cybersecurity framework alignment
- **GDPR** - Data protection (via ISO 27001 mapping)
- **Industry-specific** - HIPAA, PCI DSS, or other sector requirements

**📊 See detailed mapping table:** [Compliance Mapping](../docs/compliance-mapping.md)

## 📋 Use Case: Multi-Standard Compliance Program

### Scenario
A global technology company needs to demonstrate compliance with SOC 2, ISO 27001, and NIST CSF to enterprise customers and regulatory bodies. They manage multiple business units with varying compliance needs.

### Solution with ConfigCobra

#### Step 1: Create Standard-Specific Rule Sets
- **SOC 2 Rule Set** - Controls for Trust Services Criteria
- **ISO 27001 Rule Set** - Annex A control objectives
- **NIST CSF Rule Set** - Framework core functions
- **Combined Rule Set** - Overlapping controls for efficiency

#### Step 2: Department-Specific Schedules
- **IT Security Team** - Daily critical controls
- **Compliance Office** - Weekly comprehensive assessments
- **Business Units** - Monthly standard-specific assessments
- **Executive Dashboard** - Quarterly high-level reporting

#### Step 3: Unified Reporting with Mapping
- Generate **CIS-certified reports** and use [compliance mapping](../docs/compliance-mapping.md) to understand relationships to multiple standards
- Use summary tabs for executive reporting
- Use details tabs for technical teams
- Archive CIS reports along with mapping documentation for audit evidence

**Note:** ConfigCobra currently generates CIS-certified reports only. The compliance mapping shows theoretical relationships between CIS controls and other frameworks. Framework-specific certified reports are planned for future releases.

## 💡 Best Practices

1. **Layered Rule Sets** - Create rule sets for each standard, plus combined sets
2. **Scheduled Assessments** - Different schedules for different compliance needs
3. **Role-Based Access** - Global Readers for auditors, Operators for compliance teams
4. **Historical Tracking** - Use Reports page to track compliance trends
5. **Remediation Priority** - Focus on controls affecting multiple standards
